# Code map — where things live in ProjectA/Assets/Scripts

*(Exported from Cowork memory 2026-09-19. Verified from source 2026-08-04; UI/marker/debt section added 2026-09-16/17.)*

Custom scripts live under `ProjectA/Assets/Scripts/` (everything under `Assets/Dissonance`, `Assets/Plugins` is the vendored voice plugin — don't touch). Three main folders + UI:

**Match/** (game logic): `MatchController` (server-authoritative 9-phase machine + Instance singleton), `DungeonGenerator` (seeded room-graph grid gen, ~1500 lines), `DungeonManager`, `DungeonObjective`/`ObjectiveTrigger`/`ObjectiveHud`, `DungeonExit`, `DungeonDoors`/`DungeonDoor`, `DungeonKitPiece`, `StalkerAI` + `StalkerAnimator`, `OldMaidMiniGame` + `OldMaidCardRef`/`OldMaidCardView`, `IMiniGame` (interface), `TableSeatingManager` + `SeatStation`, `AreaEnvironment` (single writer of RenderSettings ambient/reflection by area — menu/lobby/dungeon), `LobbyLightingController` + `LightTierResponder`, `DungeonReverbZone`, `LightFlicker`, `DungeonPostGrade`, `SpawnPoint`/`DungeonSpawnPoint`, `PlayerState`, `ReadyUpInteractable`, `ChaseTVFeed` (lobby TV = RenderTexture cam following the prey during a chase → drives the Screen prop; local, no netcode), `LobbySpawnPoints`, `ElevatorController` (freight-elevator arrival/return hub, replicated timeline), `JoinBatcher` (grouped join spawning), `ScreenDeploy` (rolls the lobby projector screen down for the minigame→chase window, up otherwise), `ScreenChannelManager` (parked).

**Scripts/Legacy/** (dead, kept for future modular ART): `TileMeta`, `TileConnector`, `GreyboxTileShape`, `AffordanceNode` — old tile model, no longer used.

**Player/**: `CharacterController` + `PlayerMovement` (`MovementLocked` flag; `AddImpulse` knockback), `PlayerCamera`, `CameraFeel` (juice; `SetRumble`/`AddShake`), `PlayerInteractor`/`IInteractable`, `SeatOccupant` (F7 debug drop; `ServerRelease`), `SpectatorController` (orbit-cam spectate, `IsSpectating` netvar), `FlashlightController` + `FlashlightPickup`, `PlayerStamina`, `ScreenFeedback` (`PlayWakeUpRpc`, `Blink`), `NetworkTeleporter` (`TeleportRpc`, owner-targeted), `HeadIK`, `PlayerLocalGlow`, `LocalPlayerModelHider`, `PlayerSpawnPositioner`, `ChaseEscapeReporter`, `DungeonDebugJump`, `FaceController` + `FaceVoiceDriver` (stylized-face animation).

**Networking/**: `VoiceRoomRouter` (see voice-routing.md — DON'T rename), `VoiceSpatialProcessor` (occlusion/distance/duck), `ClientNetworkTransform` (client-auth transform for players; SeatStation uses stock server-auth NT), `SessionCursorGuard`, `DevConnectUi`/`ConnectTest`/`TransportSwitcherUI` (dev tools — strip for release).

**UI/** (2026-09-16/17 build pass): `LeaderboardView` + `LeaderboardRow` + `LeaderboardDebug` — player-keyed POOLED rows (each row follows its player), value count-up, ▲/▼ delta pop, overtake SLIDE (rows positioned by code, container has NO layout group), CHIP glyphs (◉) count = stack depth vs leader, colour = denomination tier. `debugMode` + LeaderboardDebug keys (R demo, 1 add, 2/3/6 points, D due). `LobbyScreenChrome` (status clock + round pips). `ScreenTransition` (projector signal-stutter; drives `_Brightness` via MaterialPropertyBlock; `Transition(swap)`/`Flicker()`). `MenuClock` (terminal header clock, prefix + real/frozen time; `[ExecuteAlways]`). `MenuCursor` (hardware reticle cursor on menuRoot; texture `Assets/Textures/UI/Cursor_Reticle.png`, import as Cursor type). `GlitchReveal` (facade crack). `TerminalBoot` (types boot lines + blinking cursor; `OnBootComplete` reveals menu; reuse on each CRT). `PauseMenu` + `PauseOverlay.shader` (escape overlay: full-screen blur+scanlines, sim keeps running). `CurvedUIText`/`CurvedUIGraphic` (per-axis `curvatureX`/`curvatureY` + `depthOffset`; `[ExecuteAlways]`). `MarkerSignature` (name→marker), `MarkerDebt` (balance→marker AMOUNT DUE line), `MarkerNumberLabel` (marker number). `NameInput`→`PlayerName`. `MainMenuController`, `MenuCameraDirector` (named Views, GoTo/Back), `TerminalBoot`, `StandbyScreen`, `MenuMonitorFeed`, `MenuStaticScreen`, `FocusAreaLight` (`offLevel` idle-fill), `CinematicBars` (black), `MarkerStampSequence`, `CardFace`.

**Persistent stores (static, PlayerPrefs):** `PlayerName`, `PlayerDebt` (Balance/Serviced; `Service(net)` returns milestones crossed; StartingDebt 1284502, MilestoneStep 500), `PlayerProfile` (MarkerNumber = placeholder unique id until a backend supplies the real global "Nth player"; `SetMarkerNumber()` to plug in; GamesPlayed stat). `ThemeColor`/`HouseOSPalette` exist but UNUSED (theming abandoned — colours set manually per element; palette reference in `House_OS_UI_DesignSystem.md`).

**Shaders:** `BuckshotPost` (full-screen grade, Full Screen Pass Renderer Feature), `DeadCRTScreen` (CRT/console glass, has depth/shadow passes), `ProjectorScreen` (lobby projector optics), `PauseOverlay` (escape blur+scanlines, Full Screen Pass after BuckshotPost), `EyeProc`, `InkOutline`, `CRTMaterial.shadergraph`.

**Marker prop:** `Assets/Materials/Menu/Marker/Marker.png` edited — amount/number now runtime overlays (MarkerDebt/MarkerNumberLabel), MEMBER MARKER / "Payable…" / centre watermark / duplicate DATE removed; single DATE top-right. Backup `Marker_original_backup.png` (move out of Assets). Import NPOT = None.
